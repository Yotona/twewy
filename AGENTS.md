# TWEWY DS Decompilation — Agent Guide

## Project

Reverse-engineering **The World Ends With You (DS)** to byte-perfect C via Metrowerks MWCC compilers. ROM build verification is SHA1-based; no conventional test framework.

## Setup & Build

```sh
python tools/configure.py --version usa   # generates build.ninja at the repo root (gitignored); --version jp for the Japanese release
ninja download_tools                      # downloads mwccarm, dsd, wibo, objdiff; upstream bumps required versions periodically — re-run after pulling main
ninja                                     # full build → verify SHA1
ninja check                               # check_modules + check_symbols
ninja sha1                                # verify final ROM hash only
ninja dis                                 # disassemble all modules
ninja delink                              # delink original ELF binaries
ninja apply                               # push ELF symbol names → config
ninja report / ninja objdiff              # objdiff progress tracking
```

- `mwccarm.exe` (Windows) runs via **Wibo** on Linux, Wine optionally.
- You **must** provide the following files before building (see `extract/README.md` and `docs/CONTRIBUTING.md` for exact SHA-1s):
- `extract/baserom_twewy_usa.nds` — USA ROM (required for the USA version)
- `extract/baserom_twewy_jp.nds` — JP ROM (required if building `--version jp`)
- `arm7_bios.bin` — ARM7 BIOS, placed at the **repository root** (not `extract/`)
- `build.ninja` is auto-generated by `configure.py`. Re-run it if config files change.

## Code Style (enforced by pre-commit)

- **C99**, snake_case, pointer-left alignment, 4-space indent, 127 col limit, LLVM style.
- Header guards: `#ifndef`/`#define`/`#endif`.
- Non-matching functions:
  ```c
  // Nonmatching: <reason>
  // Scratch: <decomp.me link>
  ```
- Unknown struct fields annotated `/* 0xNN */ type unk_NN;`.
- **Pre-commit**: `pre-commit run --all-files` (clang-format, YAML/JSON checks, etc.).

## Architecture

| Path | Purpose |
|------|---------|
| `src/main.c` | Game entrypoint (`main()`) |
| `src/Engine/` | Core subsystems (Overlay, File, IO, Math, Resources, Text) |
| `src/Combat/` | Battle system |
| `src/Interface/` | UI/menus (menu TUs live in `src/Interface/Menu/`; debug field/event selects in `src/Interface/Debug/Field/`) |
| `src/Field/` | Scene management + event system (`EventManager.c`, `Events.c`, `EventFlags.c`) |
| `src/Debug/` | Developer debug overlays (`Abe/`, `Horii/`, `Takami/`, `Furukawa/`, …) |
| `src/Util/` | Shared helpers: `SysFont.c` (system font, formerly `ov031.c`), `PrcMaster.c`, `MsgXls.c` |
| `libs/` | Recreated SDKs (NitroSDK, CRI ADX, MSL C/C++) |
| `config/usa/arm9/` | USA build config: overlays (48), ITCM, DTCM, delinks, symbols, relocs |
| `config/jp/arm9/` | JP build config (added 2026-08; JP ships 47 overlays — no overlay 36). Placeholder symbols must still be derived from the USA release. |
| `config/usa/build.sha1`, `config/jp/build.sha1` | Reference ROM hashes |
| `include/` | Public headers (mirrors `src/` layout) |
| `tools/` | Python build helpers |

## Key Tooling

- **`dsd.exe`** (ds-decomp) — ROM extraction, delinking, disassembly, linker config, assembly.
- **`objdiff-cli`** — Compare decompiled objects vs original ELF. Config in `objdiff.json`.
- **`tools/m2ctx.py`** — Generate decomp.me context from source.
- **`tools/permuter_import.py`** — Import functions into decomp.me permuter format (added 2026-07).
- **`tools/asset/mesdump.py`** — Extract message tables from game assets (added 2026-08).

## Decompilation Tricks

See **`docs/decomp-tricks.md`** for the full catalog of MWCC byte-matching patterns. Key quick-reference:

| Pattern | C Code | Assembly |
|---------|--------|----------|
| Dummy volatile read | `volatile_var;` | `ldr r0, [addr]` (unused) |
| Bitfield read | `struct.bitfield` | `lsl` → `lsrs` |
| Bit clear | `&= ~mask` | `bic` |
| Early return | `if (x >= N) return;` | `pophs {rN, pc}` |
| Tail call | `return func(args);` | `bx ip` |
| Shift+OR fold | `(high << 16) \| low` | `orr r0, r0, r1, lsl #16` |
| Division | `a / b` | `bl _s32_div_f` |
| do-while loop | `do { } while (cond)` | body → `cmp`/`bne` at end |
| Task dispatch | `TaskStages` union `.iter[stage]` | `blx` through indexed fptr table |
| Struct copy | `*dst = *src` | `ldm`/`stm` pairs |
| Fixed-point | `>> 12` / `<< 12` | `asr #0xc` / `lsl #0xc` |

## Quirks

- File encoding is **Shift-JIS** (VS Code workspace sets `files.encoding: shiftjis`).
- Overlay modules (`ov000`–`ov047`) load/unload dynamically at runtime.
- Some source files compile with MWCC **v1.2/sp4** instead of v2.0 (`src/Debug/Abe/Mini108.c`, `libs/{c,cpp,runtime}`).
- CI runs in custom container `ghcr.io/yotona/twewy-build:latest`.
- `symbol_mappings` in `objdiff.json` links hex addresses (`func_0200ea4c`) to readable names.
